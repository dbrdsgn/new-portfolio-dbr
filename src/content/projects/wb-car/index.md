Сделано за 2 дня в 2024 году

Задача: сделать концепт оклейки авто для регионов, привлечь новых предпринимателей на маркетплейс.

У WB нет брендинга для автомобилей, которые доставляют посылки в пункты выдачи, а у других сервисов машины узнаваемые. Нужно выбрать цветовую гамму и общий стиль позиционирования, отличающийся от конкурентов. Также учитываем, что технические ограничения позволяют использовать только 40% поверхности автомобиля. Исходя из этих особенностей, для оклейки выбран бабл-стиль, принципы которого можно будет использовать в брендировании на других носителях.

Бывают случаи, когда можно оклеить пространство вокруг баблов. Здесь используем узнаваемый градиент WB в качестве фона, чтобы не выбиваться из стилистики. Для баблов выбирается новый по восприятию черничный градиент. Каждый из баблов логически связан с соседними и образует систему информирования на машине. Дополнительно предлагается вариант с внедрением генеративных паттернов, которые дополняют баблы.
