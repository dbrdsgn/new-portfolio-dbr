# Как добавить проект

1. **Исходники.** Создать папку `cases/<адрес>/` в корне репозитория. Адрес — латиницей, через дефис: `era`, `exitdesign-site`. Он станет адресом страницы: `/projects/era/` и `/en/projects/era/`. Положить туда картинки и видео в полном размере: PNG, JPG, AVIF, GIF, MP4, MOV. Эта папка в Git не попадает.

2. **Сжатие.** Выполнить `npm run media` (или `npm run media -- era` для одного проекта). Скрипт положит в `src/content/projects/<адрес>/`:
   - картинки → AVIF шириной до 2400px;
   - GIF и видео → MP4 до 1920px, без звука.

   Уже сжатые файлы не пересчитываются, пока исходник не изменится.

3. **Текст.** В ту же папку `src/content/projects/<адрес>/` — файл `index.md`:

   ```md
   ---
   title: "Упаковка для «Эра»"
   category: packaging     # branding, web, packaging, communications, presentations, navigation, logos
   year: 2023
   cover: ./era-01.avif     # обложка карточки на главной
   featured: true           # показывать на главной
   order: 10                # необязательно: порядок внутри года, меньше — выше
   hidden: true             # необязательно: убрать карточку, страница открывается только по ссылке
   description: "…"         # необязательно: для поисковиков и превью ссылки
   ---

   Текст кейса. Абзацы — через пустую строку.
   ```

4. **Перевод.** Рядом — `en.md` с английским заголовком и текстом (переводит Claude):

   ```md
   ---
   title: "Packaging for Era"
   ---

   Case text in English.
   ```

   Без `en.md` английская страница покажет русский текст.

## Галерея кейса

На странице кейса показываются **все** картинки и видео из папки, по порядку имён файлов: `01`, `02`, `03`… Чтобы поменять порядок — переименовать исходники в `cases/` и снова запустить `npm run media` (старые сжатые файлы удалить).

Файлы с именем `preview` или `cover` — только обложка карточки, в галерею не идут.

## Порядок на главной

Сначала новые проекты (по `year`), внутри одного года — по `order`, потом по адресу папки. Если ни у одного проекта нет `featured: true`, на главной показываются все.

## Если ошиблись

Опечатка в поле, несуществующая категория или нет файла обложки — сборка остановится и напишет, в каком файле ошибка.
