# Правила кейса

Одинаковые данные на входе дают одинаковый результат на выходе. Кейс состоит только из данных, весь его вид задаёт общий шаблон.

> **Временно:** у восьми первых кейсов месяц в дате условный (`-01`), Денис поправит его сам. Порядок среди кейсов с одинаковой датой пока задаёт поле `order`.

> **Не решено:** сетка картинок, см. раздел «Сетка картинок». Пока все картинки стоят во всю ширину, независимо от размера в имени.

## Вход

Всё лежит в папке `cases/<адрес>/`. Адрес пишется латиницей, из него получается адрес страницы: `era` даёт `/projects/era/`. Папка `cases/` не попадает в git, резервная копия исходников хранится у Дениса.

```
cases/era/
  era.md                  текст и теги
  era-cover.png           обложка
  era-1-big.png           картинка
  era-2-half.png
  era-3-half.png
  era-4-big.gif           видео
  era-4-big-poster.png    постер видео
```

### Файл с текстом

```md
Название: Упаковка для «Эра»
Дата: 2023-05
Категория: Упаковка

Текст кейса одним или несколькими абзацами. Здесь же пишем, что было сделано,
и ставим ссылку на живой проект: [сайт проекта](https://example.com).

[после 5]

Текст, который стоит между картинками, сразу после картинки номер 5.
```

Текст до первой пометки стоит сверху, под названием. Пометка `[после N]` необязательна, их может быть несколько. Текст после неё идёт до следующей пометки или до конца файла.

| Поле | Обязательное | Правило |
|---|---|---|
| Название | да | Как на странице и на карточке |
| Дата | да | Год и месяц: `ГГГГ-ММ`. Месяц нужен только для порядка, на сайте виден только год |
| Категория | да | Ровно одна: Брендинг, Сайты, Упаковка, Коммуникации, Презентации, Навигация, Логотипы |
| Текст | да | Абзацы и ссылки. Без заголовков, картинок и таблиц |

### Имена картинок

Формат: `<адрес>-<номер>-<размер>.<расширение>`. Имя разбирается с конца, поэтому дефисы и цифры в адресе не мешают: `exitdesign-site-3-half.png` значит проект `exitdesign-site`, номер 3, размер `half`.

| Размер | Доля ширины | Минимальная ширина исходника |
|---|---|---|
| `big` | вся ширина | 2800 px |
| `half` | 1/2 | 2000 px |
| `third` | 1/3 | 1400 px |
| `fourth` | 1/4 | 1400 px |

- **Номер** задаёт порядок на странице. Пропуски в нумерации допустимы, повторы нет.
- **Форматы картинок:** PNG, JPG, WebP, AVIF. PSD, HEIC, TIFF и прочие нужно сначала сохранить в PNG или JPG.
- **Обложка:** `<адрес>-cover.<расширение>`, ровно одна. Это отдельная картинка, в галерею она не входит. На карточке обрезается по центру до горизонтальной пропорции 4:3.

### Видео

Имя строится как у картинки: `era-4-big.mp4`. Форматы: MP4, MOV, WebM и GIF, на сайте все становятся MP4. Постер лежит рядом: `era-4-big-poster.png`, он обязателен и показывается до начала воспроизведения.

## Выход

1. **Страница кейса на двух языках:** `/projects/<адрес>/` и `/en/projects/<адрес>/`. Это один шаблон и одни данные, различается только текст.
2. **Файлы в `src/content/projects/<адрес>/`:**
   - `index.md`: название, категория, дата, обложка и русский текст. Пометка `[после N]` записывается как `<!-- после N -->`. Список картинок не пишется: галерея собирается из имён файлов;
   - `en.md`: перевод названия и текста с теми же пометками `<!-- после N -->`;
   - картинки и постеры в AVIF, видео в MP4, с теми же именами, что на входе.
3. **OG-теги на обоих языках:**
   - заголовок: название кейса;
   - описание: начало текста кейса, примерно до 160 знаков, по границе предложения. Отдельного поля описания нет;
   - картинка: обложка.
4. **Карточка на главной** внутри своей категории. На главную попадают все кейсы.

Пример `index.md`:

```md
---
title: "Упаковка для «Эра»"
category: packaging
date: "2023-05"
cover: ./era-cover.avif
---

Текст кейса.

<!-- после 5 -->

Текст после картинки 5.
```

Категории в `index.md` пишутся латиницей: Брендинг — `branding`, Сайты — `web`, Упаковка — `packaging`, Коммуникации — `communications`, Презентации — `presentations`, Навигация — `navigation`, Логотипы — `logos`.

## Как обрабатываются данные

- **Текст** переносится дословно. Добавляются только неразрывные пробелы после предлогов и союзов.
- **Перевод** делает Клод, он лежит в `en.md`, его можно править. Любая правка русского текста сразу переносится в `en.md` без отдельной просьбы.
- **Картинки** сжимаются командой `npm run media -- <адрес>`: AVIF шириной до 2800 px, качество 80, цвет без потерь чёткости (4:4:4). Настройки лежат в `scripts/media.mjs`. При сборке Astro нарезает из них версии под разные экраны с тем же качеством 80.
- **Видео и GIF** тем же скриптом становятся MP4 шириной до 1920 px, без звука.
- **Порядок на главной:** от новых к старым по полю «Дата». Если дата совпала с другим кейсом, Клод спрашивает и записывает ответ в поле `order`.
- **Что сделано и ссылка на проект** пишутся в тексте, отдельных тегов для них нет.

## Сетка картинок

**Не решено.** Сейчас все картинки стоят во всю ширину одна под другой, размер из имени файла только записывается. Чтобы включить `half`, `third` и `fourth`, нужно решить:

1. **Неполный ряд.** Например, три `half` подряд: третьей не хватает пары. Ставить её одну слева, растягивать на всю ширину или останавливаться и спрашивать.
2. **Смешивание в ряду.** Можно ли ставить в один ряд разные размеры, например `half` + `fourth` + `fourth`.
3. **Разная высота в ряду.** Если у картинок в ряду разные пропорции, низ ряда получится неровным. Обрезать до высоты самой низкой или оставить неровный низ.
4. **Телефон.** Все размеры во всю ширину или `third` и `fourth` по две в ряд.

У Никиты так: строка делится на 12 частей (`big` 12, `half` 6, `third` 4, `fourth` 3), ряд должен давать ровно 12, размеры можно смешивать, неполный ряд — Клод спрашивает, разную высоту обрезает по центру до самой низкой, на телефоне всё во всю ширину.

- **Отступы:** один и тот же отступ `--ids__gap-m` между всеми картинками.
- **Текст между картинками** может стоять только на границе рядов.

## Поведение видео

- Автозапуск, повтор, без звука.
- Воспроизводится только в видимой части экрана. До этого показывается постер, при уходе с экрана видео встаёт на паузу.
- Если у посетителя включено «уменьшить движение», остаётся постер.
- Звуковая дорожка удаляется при подготовке файла.
- Файл больше 20 МБ: Клод предупреждает и предлагает сжать.

## Когда Клод останавливается и спрашивает

Клод не додумывает, а называет проблему и ждёт ответа, если:

- нет обложки или их несколько;
- повторяется номер картинки;
- имя файла не подходит под формат;
- категория не из списка или указано несколько;
- нет даты или месяца;
- ряд картинок неполный;
- пометка `[после N]` стоит не на границе ряда или такой картинки нет;
- у видео нет постера;
- кейсу нужно что-то, чего нет в этих правилах.

Только предупреждает и продолжает, если:

- исходник уже минимальной ширины;
- в ряду пришлось обрезать картинки;
- видео больше 20 МБ.

Сборка сама останавливается с ошибкой `[галерея]`, если имя файла не по формату, номер повторяется, у видео нет постера или пометка `<!-- после N -->` указывает на несуществующую картинку.

## Общие правила оформления

1. **Одинаковые сущности выглядят одинаково.** Теги категория и год на любой странице выглядят одинаково: размер, прозрачность, начертание и шрифт задаёт один стиль `.project-meta`.
2. **Отступы не меняются.** Все значения ниже заданы в шаблоне, у отдельных кейсов своих нет.
3. **Новые стили не создаются.** Кейс не содержит своего CSS и правок шаблона. Если правила не покрывают задачу, Клод останавливается и спрашивает. Изменение вносится в систему и сразу действует на все кейсы.

### Устройство страницы

Шаблон: `src/views/ProjectPage.astro`. Вся страница лежит в контейнере `ids__wrapper XL`.

| Сверху вниз | Стиль |
|---|---|
| Отступ от шапки | `ids__space L` |
| Название | `h1.S` |
| Теги: категория, год | `.project-meta` |
| Отступ | `ids__space S` |
| Текст | `.ids__text-width` |
| Отступ | `ids__space M` |
| Картинки и видео | `.project-gallery`, между ними `--ids__gap-m` |
| Текст между картинками, если есть | `ids__space M`, `.ids__text-width`, `ids__space M` |
| Картинки и видео, если текст был | `.project-gallery` |
| Отступ | `ids__space L` |
| Следующий проект | `.project-next` |
| Отступ | `ids__space XL` |

Текст занимает 85% ширины, на телефоне всю ширину.

## Проверка перед сдачей

- Сборка проходит без ошибок.
- Обе языковые версии страницы открываются, карточка стоит в своей категории и на своём месте по дате.
- OG-теги заполнены на обоих языках.
- Папка `cases/<адрес>/` остаётся на месте.
- Клод перечисляет маленькие исходники и прочие предупреждения.
- Коммит и публикация только по просьбе.
